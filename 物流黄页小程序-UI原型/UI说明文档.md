### 2.2 找物流（Logistics Search → Results → Detail）

**流程：** 主页「找物流」→ 城市选择 → 线路列表 → 专线公司详情

#### 2.2.1 城市选择页
- 出发地 / 目的地双选择器，支持一键交换
- 热门出发城市标签（长沙、株洲、湘潭等）
- 热门目的城市标签（广州、深圳、武汉等）
- 点击「→」按钮搜索

#### 2.2.2 线路列表页
- 顶部筛选栏：综合排序 / 评价 / 价格 / 筛选
- 公司卡片展示：
  - 公司名称 + VIP/认证标识
  - 主营业务标签（零担/整车/大件/冷链）
  - 时效参考（1-2天达）
  - 参考价（面议）
  - 查看详情 / 电话按钮

#### 2.2.3 专线公司详情页
- **基本信息区**：Logo、名称、VIP标识、成立时间、认证状态
- **经营线路区**：该公司的全部线路列表
- **🛒 代采买服务区**（橙色高亮）：
  - 是否支持代采买标识
  - 支持品类标签（五金建材、日用百货等）
  - 合作市场 + 服务费说明
  - 按钮：【提交代采买需求】
- **🏪 合作商家区**：横向滑动展示关联商家卡片
- **📷 公司实景区**：照片横向滑动
- **底部固定操作栏**：⭐收藏 / ↗分享 / 📞拨打电话

---

### 2.3 找商家（原「代采买」） 

**流程：** 主页「找商家」→ 品类/市场浏览 → 商家列表 → 商家名片 → 委托采购

#### 2.3.1 商家浏览页
- 橙色主题（区别于物流的蓝色）
- **按品类浏览**：标签式品类筛选（五金建材/日用百货/服装鞋帽…）
- **按市场浏览**：网格展示湖南各批发市场（高桥、三湘南湖、红星、马王堆）
- **推荐商家列表**

#### 2.3.2 商家名片页
- 门头照大图展示（顶部）+ 商家名称
- 基本信息：品类、经营年限、市场位置、数据来源
- 品类标签（可点击跳转同品类商家）
- **合作物流公司列表**（⭐ 核心连接点）：
  - 展示与该商家合作的物流公司
  - 标注是否支持代采买
  - 标注线路覆盖
- 按钮：【🛒 通过合作物流委托采购】

---

### 2.4 代采买需求单

**入口：** 专线详情页「提交代采买需求」/ 商家名片页「通过合作物流委托采购」

**表单字段：**
- 关联品类（多选标签）
- 收货地址（省市区 + 详细地址）
- 关联物流公司（自动带入，可修改）
- 采购清单（品名 + 数量 + 预算，可添加多行）
- 备注要求（文本）
- 采购预算上限
- 期望时效（3天内 / 一周内 / 不急）
- 提交按钮

### 2.5 湘圈（发布大厅）🆕

**页面路径：** Tab 2 → 湘圈

**功能定位：** 货主和物流专线公司共同使用的发布大厅。货主可以发布求车/求代采买信息，物流公司可以推广线路和服务。支持免费发布和付费推广两种模式。

**页面结构：**
```
┌─────────────────────────────┐
│  🏘️ 湘圈          🔍  发布  │  ← 搜索 + 文字发布按钮 🆕
├─────────────────────────────┤
│   全部  |  货主圈  | 物流圈  │  ← 三个Tab筛选
├─────────────────────────────┤
│  ┌───────────────────────┐ │
│  │ 📌 付费置顶            │ │  ← 🆕 付费帖置顶 + 金色边框
│  │ 🚛 顺达物流·李 [物流]  │ │
│  │ 长沙↔珠三角专线运输    │ │
│  │ #长沙→广州 #代采买     │ │
│  │ 👍28  💬8  ↗分享      │ │
│  └───────────────────────┘ │
│  ┌───────────────────────┐ │
│  │ 📌 付费置顶            │ │
│  │ 🚛 安捷物流·陈总 [物流]│ │
│  │ 湖南→湖北专线...       │ │
│  │ 👍15  💬4  ↗分享      │ │
│  └───────────────────────┘ │
│  ┌───────────────────────┐ │
│  │ 👤 张货主 [货主]  10分钟│ │  ← 免费帖正常排序
│  │ 求长沙→广州专线...     │ │
│  │ #长沙→广州 #五金配件   │ │
│  │ 👍12  💬5  ↗分享      │ │
│  └───────────────────────┘ │
└─────────────────────────────┘
```

**发布功能（🆕 更新）：**
- 点击「发布」按钮（原「+」改为文字按钮）弹出发布面板
- 选择发布身份：我是货主 / 我是物流
- 文本内容（支持换行）
- 添加标签（线路标签、服务标签等）
- 🆕 **付费推广开关**：¥9.9/条，开启后享有主页广告条展示 + 湘圈置顶
- 发布后立即展示在列表中，付费帖自动置顶

**🆕 付费发布规则：**
| 特性 | 免费发布 | 付费发布（¥9.9/条） |
|------|---------|-------------------|
| 湘圈内展示 | ✅ | ✅ |
| 湘圈置顶 | ❌ | ✅ 金色边框 + 📌 置顶标识 |
| 主页广告条 | ❌ | ✅ 滚动展示 |
| 有效期 | 永久 | 发布日起7天 |

**内容类型：**
| 类型 | 谁发布 | 典型内容 |
|------|--------|---------|
| 货主圈 | 货主 | 求车信息、求代采买、找线路 |
| 物流圈 | 专线公司 | 线路推广、服务介绍、优惠活动 |

### 2.7 我的（Profile）

**页面路径：** Tab 4 → 我的

**整合的功能入口：**

| 功能 | 图标 | 说明 | 页面 |
|------|------|------|------|
| 商家入驻 | 🏪 | 批发市场商家提交入驻申请 | 表单页 |

| 我的订单 | 📋 | 代采买需求单列表 | 订单列表 |

| 设置 | ⚙️ | 账号设置等（预留） | — |
| 关于我们 | ℹ️ | 平台介绍（预留） | — |

#### 2.7.1 商家入驻
- 入驻说明提示
- 表单：商家名称、门头照片上传、所在市场、市场内位置、主营品类、经营年限、联系电话
- 提交后进入审核流程

#### 2.7.2 线路收藏
- 已收藏的线路列表
- 每条显示出发→目的 + 专线数量
- 点击跳转线路搜索结果

#### 2.7.3 我的订单
- Tab栏：全部 / 进行中 / 已完成
- 订单卡片：单号、状态、品类、物流公司、采购项、预算
- 时间 + 状态标签

#### 2.7.4 浏览记录
- 按时间分组（今天 / 昨天 / 更早）
- 记录类型：公司详情、商家名片、搜索结果
- 支持单条删除 / 一键清空

### 🆕 2.8 付费推广系统

**概述：** 湘圈用户在发布动态时可选择付费推广，付费内容将在两个位置获得额外曝光。

#### 2.8.1 主页付费广告条

- **位置**：主页头部搜索栏下方，双入口卡片上方
- **样式**：金色渐变背景，左侧「🔥 付费推广」标签，右侧横向滚动内容
- **内容来源**：湘圈内所有付费发布且未过期的动态
- **展示形式**：自动横向滚动播报，每条显示用户头像 + 身份 + 内容摘要
- **交互**：点击广告条跳转至湘圈 Tab

#### 2.8.2 湘圈内付费置顶

- **排序规则**：付费帖优先于免费帖，多个付费帖按发布时间倒序
- **视觉区分**：
  - 金色左边框（`border-left: 3px solid #ff9800`）
  - 浅金色渐变背景
  - 右上角「📌 付费置顶」徽章
- **有效期**：付费发布日起 7 天内保持置顶，过期后降为普通帖

#### 2.8.3 付费发布面板

- 发布面板底部新增「付费推广」选项区
- 金色边框区域，包含：
  - 🔥 图标
  - 标题：「付费推广」
  - 说明：「¥9.9/条 · 主页广告条展示 · 湘圈置顶」
  - 开关按钮（iOS 风格滑动开关，金色激活态）
- 默认关闭，用户点击开启
- 开启后发布按钮文案不变，但提交时会记录付费标记
